BlueHeeler project aims at creating a portable tool to analyze and debug Bluetooth communication.

It allows to:

    * discover nearby BT dewices
    * connect to device, discover it's services and characteristics
    * send/receive data over BT
    * encode/decode received messages

# Installation

## Prerequisites

Blueheeler requires GTK4 to be available for your Python distribution

### Linux Ubuntu/Debian

### MacOS

`brew install cairo pkg-config gtk4 gobject-introspection`

## PyPI
Releases are available under PyPI.
`pip install blueheeler`
